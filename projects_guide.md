# Selected projects

**English** · [Русский](./projects_guide.ru.md)

## [Banking data analysis](https://github.com/ashagvaly/data-analysis-test-bank)

An analytical test assignment: SQL reconciliation of loyalty point balances and transactions, customer activation metrics, and synthetic data generators with pytest checks. Python, SQL, DuckDB, pandas.

## [Web log analysis](https://github.com/ashagvaly/AnalysisOfWebLogs)

Parse Apache access logs, load structured data into PostgreSQL, and analyze visitor and order activity with SQL. Includes market basket analysis with Apriori and association rules in mlxtend.

## [Database modeling & synthetic data](https://github.com/ashagvaly/SchemasCreatingNDataGenerating)

Model products, suppliers, and sales; generate synthetic records; load Excel datasets into SQLite using pandas and SQLAlchemy; explore the data in notebooks.

## [Hierarchical clustering experiments](https://github.com/ashagvaly/SearchForNewMethods)

An exploratory research project implementing and comparing linkage methods on synthetic samples, examining distance distortion and runtime. Python, NumPy, SciPy, pandas, Matplotlib.
